# Local AI Agent

**Local AI Agent** es un proyecto de inteligencia artificial desarrollado con Python y Ollama, orientado a ejecutar modelos de lenguaje localmente y mantener conversaciones contextualizadas.

## Objetivo

Desarrollar un agente inteligente capaz de procesar mensajes, generar respuestas y mantener un historial de conversación utilizando modelos de IA locales.

## Tecnologías

- Python
- Ollama
- Gemma 4 (gemma4:e2b)
- Git y GitHub

## Funcionalidades

- Comunicación con modelos de lenguaje locales.
- Procesamiento de mensajes.
- Historial de conversaciones.
- Respuestas contextualizadas.
- Ejecución local.

## Instalación

1. Clonar el repositorio.
2. Crear un entorno virtual.
3. Instalar las dependencias.
4. Instalar Ollama.
5. Descargar el modelo Gemma 4.
6. Ejecutar el agente.

## Ejecución

```bash
python main.py
```
